# Rendimiento

Qué significa que el juego "corra bien", medido con datos y no con una sensación.

- **La decisión:** [ADR-0020](../adr/0020-requisitos-y-presupuestos-de-rendimiento.md).
  Fija la máquina de referencia (Dell XPS 13 9360 con Intel UHD 620), los 60 fps, la
  resolución interna de 640×360, los requisitos R1 a R5 y el protocolo de medición.
- **Los presupuestos por sistema:** [`presupuestos.md`](presupuestos.md), un documento
  vivo que se corrige con cada medición.

Las herramientas de profiling se deciden en el ADR-0021.
