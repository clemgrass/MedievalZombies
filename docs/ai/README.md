# IA

Decisiones e investigación de la IA de los zombies: cómo deciden qué hacer, cómo se
enteran de la caballera, cómo se coordinan para atacar y cómo navegan el escenario.

**Estado:** [ADR-0023](adr/0023-ia-y-navegacion.md) aceptado: los zombies deciden con un
árbol de comportamiento plano, navegan una navmesh propia que genera el cocinador, se
esquivan con ORCA y atacan por turnos con fichas. Investigación:
[`research/prototipo-de-ia-y-navegacion.md`](research/prototipo-de-ia-y-navegacion.md).

- [`adr/`](adr/): ADRs del área.
- [`research/`](research/): notas largas de investigación y resúmenes de papers.
