# UI

Decisiones e investigación de la interfaz del jugador: el HUD, los subtítulos, los menús,
el texto y las fuentes, los idiomas y cómo se navega con teclado, mouse y gamepad.

**Estado:** [ADR-0026](adr/0026-ui-hud-y-menus.md) aceptado: una UI propia en
*immediate mode*, dibujada a 640×360 con fuentes de píxeles; 0 HUD por defecto, con
señales en la caballera y ayudas que se prenden una por una; subtítulos que no se
apagan; español e inglés; y accesibilidad medida contra las Game Accessibility
Guidelines, las XAG e ISO/IEC 40500:2025. Investigación:
[`research/prototipo-de-ui.md`](research/prototipo-de-ui.md).
