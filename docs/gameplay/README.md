# Gameplay

Decisiones e investigación de las reglas del juego: la fuerza del tajo, la armadura, qué
pedazo sigue vivo, la espada clavada y los agarres.

**Estado:** [ADR-0018](adr/0018-combate-y-desmembramiento.md) aceptado: la fuerza se
gasta por área con un umbral de entrada en el metal, la espada clavada es una secuencia
de *quick time*, y el plano del tajo pasa por el pecho. Investigación:
[`research/prototipo-del-combate.md`](research/prototipo-del-combate.md).
