# Animación

Decisiones e investigación del sistema de animación: esqueletos, clips, skinning, IK y
la animación de los zombies mientras se cortan y después de perder partes.

**Estado:** [ADR-0015](adr/0015-sistema-de-animacion.md) aceptado: animación por
capas (clips, IK y física), LBS deformado en la GPU, y en la CPU solo el zombie que se
corta. Investigación:
[`research/skinning-y-prototipo-del-tajo.md`](research/skinning-y-prototipo-del-tajo.md).

- [`adr/`](adr/): ADRs del área.
- [`research/`](research/): notas largas de investigación y resúmenes de papers.
